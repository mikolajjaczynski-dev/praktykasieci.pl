# praktykasieci.pl

Strona „już wkrótce” bloga **Praktyka sieci** (start: 5 stycznia 2027). Jeden plik `index.html`
z licznikiem sprawdzanym w przeglądarce, czcionki hostowane lokalnie w `fonts/` (bez Google Fonts, RODO).

- `404.html` przekierowuje nieistniejące podstrony na stronę główną <https://praktykasieci.pl/>.
- W repozytorium nie ma treści przyszłych artykułów. Pełna strona bloga zostanie wgrana w dniu startu.

Publikowana przez GitHub Pages (gałąź main, katalog główny), domena w `CNAME`.
Poprzednia wersja (przekierowanie całej domeny na modelesieci.pl) jest w historii gita.
